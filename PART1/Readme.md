# RaceDay — Race Management Platform

## System Overview
RaceDay is a comprehensive, modern race management web platform designed to streamline event planning, participant registration, category structuring, and real-time live result tracking. Built with a professional dark-mode aesthetic utilizing rich blues (`#00008B`, `#191970`, `#4169E1`), the platform provides seamless workflows for both event organizers and participants, complete with embedded route mapping and external weather service integrations.

---

## User Roles & Capabilities

### 1. Participant
* **Account Management:** Register secure accounts, log in, update personal profiles, and manage notification/unit preferences.
* **Event Discovery:** Explore upcoming races, filter by distance or category tiers, and view historical race archives with photo logs.
* **Route & Weather Inspection:** View GPS course routes, elevation profiles, and live weather conditions (temperature, wind, and forecasts) for specific event venues.
* **Enrolment & Leaderboards:** Enrol in specific race categories (automatically assigned a unique bib number), track active enrolments, view live leaderboards, and download official finisher certificates.

### 2. Organiser
* **Event Lifecycle Management:** Create, update, and permanently delete race events with validation safeguards.
* **Category & Tier Structuring:** Add and manage custom distance categories, age brackets (e.g., Junior, Open, Masters), and entry fees per event.
* **Participant Roster Oversight:** Review enrolled participant rosters and export data.
* **Result Capturing:** Capture official finish times and positions for participants to automatically update live leaderboards.
